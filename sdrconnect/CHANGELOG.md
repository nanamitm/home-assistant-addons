# Changelog

## 0.1.0

- Initial release, tracking SDRconnect build `93b44446f` (2026-08-17).
- Server mode on TCP 50000 and headless websocket mode on 5454.
- Receiver selection by serial number, plus antenna, gain, AGC, bias-T,
  sample rate, centre frequency and notch filter options.
- Host networking so that client *Discover* works, and USB access under
  protection mode.
