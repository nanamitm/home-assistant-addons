# JK EPG Home Assistant Add-on

Home Assistant Ingressで日本のテレビ番組表を表示するアドオンです。

番組表／現在・次表示、複数ジャンル・チャンネルフィルター、取得元診断、手動更新に加え、Home Assistantの番組センサーとカレンダーを提供します。amd64とaarch64に対応しています。

番組表取得ロジックはMITライセンスの [jkcnsl-cache](https://github.com/nanamitm/jkcnsl-cache) から切り出しています。詳細は [DOCS.md](DOCS.md) を参照してください。
